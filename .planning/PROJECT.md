# 2B3C (рабочее название продукта)

## What This Is

**2B3C** — маркетплейс бриллиантов и ювелирных изделий для **рынка РФ**, с двумя основными сценариями покупки в каталоге: **готовое украшение** и **конфигуратор «оправа + камни»** (выбор изделия, затем подбор камней под него). Ориентир по продуктовому опыту — **Rare Carat** ([rarecarat.com](https://www.rarecarat.com/)), с адаптацией под локальные платежи, доставку и регуляторику. Технически это тот же монорепозиторий **Stonee** (`stonee-workspace`): код, Docker и доменные сервисы сохраняют текущие имена; **бренд в UX/коммуникациях** переводим на **2B3C** поэтапно.

**Состояние:** **brownfield** — работаем с уже существующей «недоделкой»: часть потоков и интеграций есть, цель GSD здесь — **свести продуктовый замысел с кодом**, закрыть пробелы и стабилизировать поведение, а не объявлять проект с нуля.

## Core Value

Два понятных пути покупки (готовое / собери сам) + **прозрачная оплата** и **отслеживание** этапа **доставки** или **изготовления и доставки** — без потери доверия на дорогом чеке.

### Out of Scope

- Полный ребрендинг npm-пакетов `@stonee/*` и переименование репозитория — только после явного решения (дорого по координации).
- Копирование всего функционала Rare Carat «один в один» — ориентир, не чеклист паритета.

## Context

- Конкурентный ориентир: Rare Carat — онлайн-покупка бриллиантов с упором на сравнение и доверие.
- Целевая география: **РФ** (язык, платежи, логистика, юридические формулировки, поддержка).
- Кодовая база: см. `.planning/codebase/*` (обновлять при крупных изменениях архитектуры).

## Constraints

- **Tech stack**: зафиксирован монорепо React + Fastify + MongoDB + Redis (см. `info/ARCHITECTURE.md`).
- **Brand vs repo**: продукт **2B3C**, репозиторий пока **Stonee** — не смешивать в runtime-конфиге без миграции.
- **Качество**: изменения поведения сопровождаются `pnpm run test`, `pnpm run lint` (где настроено), `pnpm run smoke` при затронутых сервисах.
