## API contract snapshot

- **Cart item `type` enum** (Mongoose `CartItemSchema` in `services/order-service/src/models/Cart.ts`): matches source `enum: ['diamond', 'setting', 'jewelry', 'bespoke']`.
- **Cart add** `POST /cart/:sessionId/add`: persists request body items with client-supplied `price`; recalculates cart `totalAmount` as sum of line `price * quantity` on the server from those client values (no catalog round-trip here).
- **Checkout** `POST /checkout`: loads the cart, calls pricing-service `POST /validate-prices` with `items: cart.items`, receives items whose `price` fields are **replaced** with upstream-derived values: `jewelry` resolves via jewelry collections by `productId`; `bespoke` resolves diamond and setting prices via `bespokePair.diamondId` and `bespokePair.settingId` as catalog and settings SKUs respectively, and sets bespoke line price to their sum; then persists the order with validated line prices and `totalAmount`. This is the authoritative CAT-03 boundary: **cart display may diverge until checkout** unless UI uses the same rules as pricing.
