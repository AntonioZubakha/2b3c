## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → gateway | Checkout и pay только с валидным JWT (кроме публичного cart/webhook). |
| Stripe → webhook | Подпись `stripe-signature`, сырой body. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Tampering | Клиент подменяет адрес после валидации | mitigate | Нормализация только на сервере; не доверять нестандартным ключам JSON. |
| T-02-02-02 | Elevation | Расширение публичных путей gateway | mitigate | Минимальный diff; peer-review в SUMMARY. |
| T-02-02-03 | Repudiation | Webhook удаляет lock при ошибке | mitigate | Сохранить или усилить идемпотентность; при изменении — описать в SECURITY.md. |
| T-02-02-04 | Information disclosure | Детальные ошибки Stripe в ответах API | mitigate | Общие сообщения клиенту, детали в логах. |
| T-02-02-05 | Denial of service | Aggressive retry на pay | accept | Rate limit gateway; не изменять без метрики. |
</threat_model>
