<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → API gateway | Недоверенные JWT, sessionId, тела checkout; rate limit per IP. |
| Gateway → order-service | Доверенные `x-user-id` / роль только если запрос прошёл JWT; исключение — публичные пути. |
| Stripe → order-service | Webhook подпись и сырой body; повторная доставка событий. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Tampering | `POST /checkout` body (цены, позиции) | mitigate | Серверная валидация через pricing-service уже в пути; аудит подтверждает отсутствие доверия к клиентским ценам (см. matrix). |
| T-02-01-02 | Spoofing | Simulated pay при пустом Stripe ключе | mitigate | Задокументировать в GAP/SECURITY; 02-02 — fail-closed или явный env-only флаг per CONCERNS. |
| T-02-01-03 | Repudiation | Webhook обработка без корректного audit trail | accept | Логи Fastify; детальный контроль — вне scope аудита, зафиксировать в GAP-WEBHOOK-01. |
| T-02-01-04 | Information disclosure | Ошибки checkout 500 без кода | mitigate | Аудит перечисляет, какие ответы утечки дают; 02-02 при необходимости выровнять сообщения. |
| T-02-01-05 | Denial of service | Публичный cart без строгих лимитов | mitigate | Указать bucket mutate в матрице gateway; рекомендации — в 02-02/docs. |
| T-02-01-06 | Elevation | Подмена `shippingAddress` для чужого userId | mitigate | Checkout требует JWT; cart привязан к sessionId — отразить в traceability. |
</threat_model>
