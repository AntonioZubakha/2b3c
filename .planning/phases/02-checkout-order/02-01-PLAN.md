## Gateway vs order-service

Источник: `apps/api-gateway/src/server.ts` — декоратор `authenticate` (~L122–180), `rateLimitMaxForRequest` (~L53–72), прокси `prefix: '/api/order'` → `order-service:3000` (~L220–223).

### Условия `isPublic`, касающиеся `/api/order`

| Условие (смысл) | Метод и путь на gateway | Upstream order-service |
|-----------------|-------------------------|-------------------------|
| Stripe webhook без JWT | `POST` + `url.startsWith('/api/order/webhooks/stripe')` (~L144–145) | Плагин: `prefix '/webhooks'` + `POST '/stripe'` → **`POST /webhooks/stripe`** на сервисе (`server.ts` registerStripeWebhook) |
| Гостевая корзина | `url.startsWith('/api/order/cart')` && (`GET` \|\| `POST` \|\| `DELETE`) (~L145–146) | `GET/POST/DELETE` под `/cart/...` — `order-service/src/server.ts` |
| Health | `GET` + `/api/.../health` (~L142) | `GET /health` order-service |

**Не публично (требуют JWT после `jwtVerify`):** `POST /api/order/checkout`, `POST /api/order/orders/:id/create-payment-intent`, `POST /api/order/orders/:id/confirm-stripe-payment`, `POST /api/order/orders/:id/pay`, `GET /api/order/my-orders`, supplier/admin order routes — они **не** входят в `isPublic`, значит **checkout и оплата только с валидным Bearer** (ORD-01: гость не оформит заказ без логина на шлюзе).

### Rate limit для webhook

- `POST` на путь, начинающийся с `/api/order/webhooks/stripe` → лимит **`STONEE_GATEWAY_RATE_LIMIT_WEBHOOK_MAX`** (default **5000**/мин) — `rateLimitMaxForRequest` ~L57–58.

### Риски ORD-01 (корзина vs оплата)

- **Гостевой cart** публичен по `sessionId`; **checkout** привязывает заказ к `x-user-id` из JWT и очищает корзину по `sessionId` — подмена чужого `shippingAddress` без JWT на checkout **невозможна** через gateway; подмена sessionId чужой корзины возможна для публичных cart-операций (риск кражи «чужой» корзины как DoS/шутка), но checkout требует того же пользователя с JWT (см. traceability).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → API gateway | Недоверенные JWT, sessionId, тела checkout; rate limit per IP. |
| Gateway → order-service | Доверенные `x-user-id` / роль только если запрос прошёл JWT; исключение — публичные пути. |
| Stripe → order-service | Webhook подпись и сырой body; повторная доставка событий. |
