# Jewelry Settings — гайд по закрепкам камней

Документ описывает доменную модель закрепок (settings), используемую в Stonee, и правила совместимости «украшение ↔ закрепка ↔ камень». Используется фронтом (`/craft`) и сервисами **jewelry-service** / **pricing-service** / **order-service**.

---

## Покупательский путь (canonical)

```
1. Выбор украшения  →  2. Выбор камня  →  3. Подсчёт счёта
   (setting mount)      (diamond)            (summary + checkout)
```

На шаге 1 пользователь выбирает **категорию изделия** и **тип закрепки** (`SettingType`). На шаге 2 показываются только камни, чья **форма** входит в `compatibleShapes` выбранной оправы.

---

## Восемь способов закрепки (Setting Types)

### 1. Prong / Claw — крапановая закрепка

4–6 тонких «лапок» обхватывают камень сверху.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Кольца (помолвочные, солитеры), серьги-гвоздики, кулоны |
| **Что садят** | Бриллианты круглой огранки, сапфиры, рубины, изумруды (от 0,5 кт) |
| **Совместимые формы** | Round, Oval, Cushion, Princess, Emerald, Pear, Marquise, Heart, Asscher, Radiant |
| **Плюсы** | Максимум света через камень |
| **Минусы** | Лапки могут зацепляться, нужна подтяжка |

### 2. Bezel — безельная оправа

Камень обрамлён тонкой металлической каёмкой.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Кольца, кулоны, браслеты, серьги |
| **Что садят** | Кабошоны, мягкие камни, нестандартные формы |
| **Совместимые формы** | Round, Oval, Cushion, Emerald, Asscher, Radiant, Pear, Marquise, Heart, Princess |
| **Плюсы** | Защита, гладкая поверхность |
| **Минусы** | Меньше света по периметру |

### 3. Channel — канальная

Камни в пазу между двумя стенками металла.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Обручальные, eternity, теннис |
| **Совместимые формы** | Princess, Emerald, Asscher, Radiant |
| **Плюсы** | Плотный ряд, не цепляется |
| **Минусы** | Сложный ремонт |

### 4. Pavé — дорожная закрепка

Мелкие камни в углублениях.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Ободки, шинки, декор halo |
| **Совместимые формы** | Round (преимущественно) |
| **Плюсы** | «Алмазная пыль», блеск |
| **Минусы** | Риск выпадения мелочи при ударе |

### 5. Peg / Post — на штифте

Для камней с отверстием (жемчуг, бусины).

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Подвески, кольца с жемчугом |
| **Совместимые формы** | Для классических бриллиантов редко |
| **Плюсы** | Подходит для отверстий |
| **Минусы** | Не для классической огранки |

### 6. Screw — с винтом

Съёмная фиксация винтом.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Кулоны, винтаж, трансформеры |
| **Совместимые формы** | Round, Oval, Emerald, Cushion (крупные) |
| **Плюсы** | Съёмный камень |
| **Минусы** | Больше металла |

### 7. Tennis — теннисная

Четыре когтя на камень в линию.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Браслеты, колье |
| **Совместимые формы** | Round |
| **Плюсы** | Ровная линия блеска |
| **Минусы** | Один калибр |

### 8. Invisible — «невидимка»

Пазы по бокам камней, визуально монолит.

| Параметр | Значение |
| :--- | :--- |
| **Куда** | Крупные кольца, elite SKU |
| **Совместимые формы** | Princess, Asscher |
| **Плюсы** | Monolith-эффект |
| **Минусы** | Дорогая работа, калибровка |

## Сводная таблица: украшение → способ → камень

| Украшение | Допустимые `SettingType` | Типичные камни | Огранки |
| :--- | :--- | :--- | :--- |
| **Кольцо помолвочное** | Prong, Pavé (декор), Bezel, Three-stone | Бриллиант, сапфир, рубин | Round, Oval, Cushion, … |
| **Eternity / обручальное** | Channel, Pavé | Бриллианты | Round, Princess, Emerald, Asscher |
| **С жемчугом** | Peg | Жемчуг | — |
| **Теннис** | Tennis, Channel | Бриллианты | Round / прямоугольные |
| **Кулон** | Bezel, Prong, Peg | Бриллианты, кабошоны | Разные |

---

## Логика выбора (кратко)

| Фактор | Влияние |
| :--- | :--- |
| Твёрдость | Мягкие камни → Bezel / Peg |
| Огранка | Round → Prong / Tennis / Pavé; прямоугольные → Channel / Invisible |
| Носка | Повседневно → Bezel / Channel; «выход» → Prong / Halo |

## Доменная модель в коде

### `SettingType`

```ts
export type SettingType =
  | 'Prong'
  | 'Bezel'
  | 'Channel'
  | 'Pavé'
  | 'Peg'
  | 'Screw'
  | 'Tennis'
  | 'Invisible';
```

Источник: `packages/shared-types/src/index.ts`.

### `JewelryCategory`

```ts
export type JewelryCategory = 'Ring' | 'Earrings' | 'Necklace' | 'Bracelet';
```

### `SETTING_TYPE_INFO`

В shared-types задаётся англоязычный справочник (`label`, `tagline`, `compatibleShapes`, …). Это **канон для данных и английского UI-fallback**.

### `ISetting` и `inferSettingType`

Поле `settingType?: SettingType` опционально для обратной совместимости. Если нет — тип выводится из `style` (`Solitaire` | `Halo` | `Pavé` | `Side-stone` | `Three-stone`) функцией `inferSettingType()`.

## Локализация UI (русский / английский)

Для экрана `/craft` и коллекций пользовательские подписи к таксономии и к **SKU из сида** вынесены в i18n-модуль **`catalog`** (`apps/frontend/src/i18n/locales/ru/catalog.ts`, `en/catalog.ts`) и хелперы `src/lib/displayI18n.ts`. Так в БД остаются английские поля API, а в RU показываются переводы.

---

## Связь с pricing-service

`POST /api/pricing/validate-prices` для bespoke: `bespoke.price = diamond.price + setting.price`. Совместимость форм фильтруется на фронте; при чекауте order-service должен отклонять неконсистентные пары.

---

## Не покрыто в MVP

- Pavé только как декор вокруг центра в некоторых сценариях.  
- Tension / burnish / flush — вне текущего `SettingType`, до появления данных поставщиков.
