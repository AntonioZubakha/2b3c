# 2B3C — продукт (рабочее имя)

**Репозиторий и пакеты** пока называются Stonee (`stonee-workspace`, `@stonee/*`). **Публичное имя продукта** — **2B3C** (отсылка к образу «два бриллианта в три карата…»).

## Назначение

Онлайн-маркетплейс **бриллиантов и ювелирных изделий** для **рынка РФ**. Качественный ориентир по опыту покупки и доверия — **Rare Carat** ([rarecarat.com](https://www.rarecarat.com/)); функциональный паритет не требуется.

## Два сценария в каталоге (покупатель)

1. **Готовое украшение** — основной вход **`/collections`** (`JewelryPage`): готовый SKU → корзина **`/cart`** → оформление **`/checkout`**.
2. **Оправа + камни** — конфигуратор **`/craft`** (`CraftPage`): оправа → совместимые камни → на финальном шаге добавление bespoke в **`/cart`** (гость: редирект на **`/auth?redirect=%2Fcart`**) → далее тот же **`/checkout`**. Отдельного «мгновенного» чекаута только из craft нет — один общий контур после корзины.

## После каталога (оба сценария)

- **Корзина** **`/cart`** и **оплата** **`/checkout`** общие для обоих путей (Stripe на checkout; сценарии под РФ — поэтапно).
- **Отслеживание:** доставка **или** изготовление и доставка — статусы и копирайт должны совпадать с тем, что реально отдаёт API.
