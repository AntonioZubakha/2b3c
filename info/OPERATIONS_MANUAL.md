# Stonee — операционный мануал (черновик)

Документ задаёт **общий язык** для логистики и комплаенса и фиксирует **кандидатные схемы** после стыковки `MASTER_ENTERPRISE.md` и legacy `GO_TO_MARKET_RU_LEGACY.md`.  
**Не является** таможенным, налоговым или юридическим заключением: пороги пошлин, ГИИС ДМДК, пробирный учёт и квалификация «личного импорта» vs B2C **обязательно** подтверждаются **брокером и юристом** по выбранному маршруту.

---

## 1. Четыре оси (арбитраж документов)

| Ось | Вопрос | Типичный выбор для старта Stonee |
|-----|--------|----------------------------------|
| **Company jurisdiction** | Где зарегистрировано юрлицо, контракты, выручка | **UAE** (напр. DMCC) |
| **Payment jurisdiction** | Где открыт счёт / какой провайдер принимает оплату | **UAE + международные** каналы ($, crypto и т.д. — по комплаенсу); не смешивать с «страной клиента» |
| **Fulfillment jurisdiction** | Откуда физически уходит груз и какой маршрут до клиента | **Surat → UAE hub → клиент** или **UAE → ателье в СНГ → клиент** |
| **Regulatory jurisdiction** | Какие режимы маркировки/налога/таможни включаются | Зависит от **маршрута** и того, **ювелирное изделие** это или **loose** + монтаж локально |

Путаница «рынок = РФ» без этих четырёх строк приводила к противоречию: **русскоязычные клиенты и доставка в РФ** не равны **«компания и эквайринг в РФ»**.

## 2. Схемы (от простой к сложной)

### Схема A — «Чистый мост» (cross-border из UAE)

Клиент (в т.ч. РФ) → оплата вне российского картового стека → отгрузка из UAE (после QC) → курьер (DHL и т.п.) → таможня у получателя.

- **Плюсы:** одно юрлицо, нет российского ООО на старте.  
- **Минусы / DD:** предсказуемость пошлин и UX «оплата при получении»; ограничения по способам оплаты для части аудитории; проверка ограничений перевозчика на ювелирку.

### Схема B — «Локальный партнёр в РФ» (B2B2C)

Stonee UAE → **опт / контракт** российскому ювелиру → розница и ГИИС/пробирка **на стороне партнёра**.

- **Плюсы:** локальные карты и compliance на партнёре.  
- **Минусы:** маржа, контроль бренда, SLA.

### Схема C — «Ателье в СНГ»

Камни/полуфабрикат UAE → **ателье в KZ / AM / др.** → монтаж и локальная выдача или дальнейшая отправка.

- **Плюсы:** ближе к русскоязычному рынку, альтернативные платёжные коридоры (по отдельному DD).  
- **Минусы:** второй контрактный контур, QC, сроки.

После выбора **одной** основной схемы для пилота — зафиксировать в этом файле версию «v0.1» с датой и ответственным.

### 2.1 Default pilot (Month 1–6) — **Схема A**

Чтобы не спорить вечно о трёх схемах без execution, пилот по умолчанию:

- **Маршрут:** cross-border **UAE hub** → клиент (курьер класса DHL/аналог после DD).  
- **Платежи:** **Stripe (USD и др. карты)** + roadmap **SWIFT / crypto** (см. `MASTER_ENTERPRISE.md` §10.1 — в коде пока в основном Stripe).  
- **Таможня:** по умолчанию клиент платит пошлины при получении; **DDP** — опция с месяца ~4 после метрик отказов.  
- **Fallback:** если **>20%** отказов по причине «платёж/доставка» — включить обсуждение **Схемы B** (B2B партнёр локально).

**Триггеры пересмотра схемы (черновик):**

| Сигнал | Действие |
|--------|----------|
| Отказ по платежам **>30%** | Добавить каналы / **Схему C** (ателье в СНГ) после юр. DD |
| Таможенные задержки **>15%** заказов | DDP или партнёрский импорт (B) |
| **CAC >$200** устойчиво | Сместить акцент на **B2B (B)** или сильнее органику |
| Регуляторное письмо / смена санкций | Стоп-линия, юрист, пауза канала |

## 5. Lean pilot (90 дней): от кода к первому чеку

**Философия:** цель **не** «идеальный продукт», а **10–20 оплаченных заказов** с полным циклом (оплата → QC → доставка → отзыв) и **записанными** метриками. Без этого P&L остаётся assumptions.

**Готово ≠ бизнес:** бизнес — это клиент с **$2,4K** на счёте, изделие в руках через **реально измеренные** дни и отсутствие сюрпризов по AML/таможне.

## 6. Фазы (черновик дорожной карты ops)

### Phase 0 — Операционный фундамент (недели 1–4)

| Задача | Критерий готовности |
|--------|---------------------|
| DMCC / лицензия в работе | Пакет подан или лицензия получена; ответственный назначен |
| Счёт UAE / SWIFT | Счёт открыт или понятный блокер + план B |
| **KYC** (Sumsub/Onfido и т.д.) в `user-service` + блок checkout сверх порога | Тестовый проход на staging |
| **USDT** (или иной согласованный crypto) в `order-service` | Тестовая микро-транзакция |
| **Surat agent** (GIA/IGI, part-time + backup контакт) | Подписанный контракт / SOW |
| **3 MSA** поставщиков, **bulk**-фиды | Три рабочих фида в catalog |
| **Тестовая отправка** Surat → Dubai → тестовый адрес | Трек, пошлины/сроки записаны |
| **Mongo backup** ежедневно | Cron/systemd + S3; **квартальный** restore-test |

**Не делать в Phase 0:** buffer stock; полный RapNet live на миллионы запросов; крупный paid ads до working unit economics; отдельный CS hire — **founder-led** продажи и WhatsApp.

### Phase 1 — Пилот продаж (недели 5–10)

- **Продукт:** только **loose + bespoke** (zero).  
- **Каналы:** organic IG/TikTok + личный нетворк + 1–3 микро-инфлюенсера (barter / малый бюджет).  
- **Учёт:** каждый заказ — строка в **Google Sheet** (дата, канал, оценка CAC, SKU, статус, инциденты) до нормального BI.

| KPI | Target | Anti-target (стоп и разбор) |
|-----|--------|------------------------------|
| Оплаченные заказы | **10+** | **<5** |
| Blended CAC пилота | **<$250** | **>$400** → pivot канала или схема B |
| Median доставка (раб. дни) | **<21** | **>35** → логистика / SLA |
| Возвраты | **<10%** | **>25%** → QC/описание |
| NPS | **>50** | **<30** → продукт/сервис |
| Chat → order (консьерж) | **>15%** | **<5%** → аудитория или UX |

### Phase 2 — Реальный unit economics (недели 11–14)

Разнести **CAC по каналам** (organic/referral/influencer/Meta/Google). Пересчитать **маржу** по фактурам поставщика и чекам логистики. Решение: **зелёный** (масштабировать paid умеренно) / **жёлтый** (органика + B2B) / **красный** (стоп, смена модели) — см. матрицу внешних ревью.

### Phase 3 — Масштаб или коррекция (мес. 4–6)

Только после «зелёного» или осознанного «жёлтого» сценария: маркетинг $10–15K/мес, CS hire, 360° на топ-SKU, усиление Surat full-time. **Не** строить «идеальный» 3D/ML/AI-concierge до **доказанной** экономики (`MASTER_ENTERPRISE.md` §13).

## 8. Что не делать (анти-паттерны)

- Обещать **«7 дней»** и «быстрее всех» при zero-inventory — убьёт доверие.  
- **Stonee Pro / B2B портал** до **$300–500K GMV/мес** (см. §3.1 MASTER).  
- **Buffer stock** в первые **~6 мес** пилота — см. §10.3 MASTER + §6 выше.  
- Полный **LLM-concierge** и тяжёлый **3D-конфигуратор** до доказанных продаж и runway.  
- Игнорировать **санкции / AML** — может остановить бизнес за неделю.
