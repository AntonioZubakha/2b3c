# Dev Seed

Сервис для быстрого развёртывания dev-окружения: создаёт тестовых пользователей и загружает сток продуктов.

- **Продавцы:** seller1@dev.local, seller2@dev.local (у каждого по 5 продуктов после обработки файла).
- **Покупатели:** buyer1@dev.local, buyer2@dev.local.
- **Пароль у всех:** `Password123`.

Запускается один раз после старта `lgdx-server-dev` (идемпотентно: повторный запуск не дублирует пользователей и не перезаливает продукты, если они уже есть).

Сделки можно гонять вручную во фронте: логин → корзина → оформление сделки.
